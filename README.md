# camargobocaletto.com

Site institucional da Camargo Bocaletto Ltda: página inicial e política de privacidade.
HTML estático, sem build. Publicado pelo GitHub Pages (branch `main`, raiz); o DNS fica na
Porkbun (A do apex para o GitHub Pages, `www` em CNAME), com o e-mail do Google Workspace
intocado (MX, SPF, DKIM).

A URL da política (`/privacidade.html`) é a que vai no app da Meta.
